# Materiais auxiliares

- `tools/`: importação das fontes públicas, verificação dos dados e auditoria de endereços.
- `reports/links.json`: resultado datado das consultas aos endereços externos.
- `requirements-data.txt`: dependências dos importadores.
- `sisu.json` e `enem-usp.json`: extrações intermediárias preservadas para reconstrução; não são solicitadas pelo site.

As bases usadas pelo navegador ficam em `../Arquivos Principais/`. Os importadores localizam os destinos a partir de sua própria pasta. Os documentos originais devem estar em `../history-sources` em relação à raiz do repositório, conforme as instruções do README principal. Nenhuma credencial ou documento pessoal é necessário.
