# Diretrizes do projeto

- Publicar exclusivamente neste repositório e no GitHub Pages.
- Manter dados oficiais, proveniência por edição e valores ausentes como null.
- Não equiparar automaticamente carreiras entre edições nem apresentar a linha de referência como probabilidade de aprovação.
- Conferir o layout amplo e estreito, a acessibilidade dos controles e as exportações ao alterar essas funções.
- Evitar rótulos populares como explicações científicas. Usar definições explícitas e separar dados, cálculo e interpretação.
